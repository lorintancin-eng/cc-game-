## Core Stability (always run, every build)

1. **Launch without crash**: open `project.godot` → game launches to CharacterSelectPanel without parse errors or broken resource references
2. **Character select**: click "修行者" → CharacterSelectPanel closes → Player spawns at origin → camera follows
3. **Character select (Sun Wukong)**: click "弼马温" → SunWukongV2 spawns → 4 skill slot icons visible in HUD → cooldowns display 0/max correctly
4. **Run starts without errors**: first 10 seconds — enemies spawn, auto-weapons fire, HP bar updates, timer counts up — no Godot errors in console
