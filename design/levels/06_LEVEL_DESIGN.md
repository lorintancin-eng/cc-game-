## 1. 关卡设计原则

1. 每关 5 分钟单局
2. **节奏曲线明确**（入劫 → 妖潮 → 镇妖碑 → 精英 → 预警 → Boss）
3. 视觉氛围统一（暗黑志怪）
4. **关卡数据驱动**（StageDirector @export 配置）

## 3. 关卡节奏曲线（统一模板）

每关都遵循统一的 5 分钟节奏曲线：

| 时间 | 阶段 | 玩法重点 | 敌人组合 |
|---|---|---|---|
| 0:00-1:00 | **入劫** | 玩家熟悉、积累第一波修为 | 基础怪 100% |
| 1:00-2:00 | **妖潮增强** | 密度提升、速度/群体怪 | 基础 + 群体 / 高速 |
| 2:00-3:00 | **镇妖碑显现** | 引导玩家离开安全区 | 基础 + 镇妖碑风险事件 |
| 3:00-4:30 | **精英压迫** | 精英 + 组合 | 基础 + 精英 + 肉盾 |
| 4:30-5:00 | **妖王预警** | 屏幕提示妖气暴涨 | 普通密度降低 + 警示 UI |
| 5:00 后 | **妖王降临** | Boss 出现 | Boss + Boss 召唤物 |

### 3.1 StageDirector 实施（v0.2）

`stage_director.gd` 通过 @export 字段配置：

```gdscript
@export var stage_duration: float = 300.0          # 5 分钟
@export var boss_warning_time: float = 270.0       # 4:30
@export var demon_seal_spawn_time: float = 120.0   # 2:00
@export var demon_seal_min_spawn_distance: float = 200.0
@export var demon_seal_max_spawn_distance: float = 280.0
@export var first_elite_time: float = 180.0        # 3:00
@export var second_elite_time: float = 240.0       # 4:00
```

### 3.2 阶段事件触发

每个时间点触发一次（用 `_is_xxx_triggered` flag 保证）：

| 时间 | 事件 | 触发函数（示例） |
|---|---|---|
| 120s | 生成镇妖碑 | `_spawn_demon_seal()` |
| 180s | 生成第一只精英 | `_spawn_elite()` |
| 240s | 生成第二只精英 | `_spawn_elite()` |
| 270s | 显示 Boss 预警 UI | `_show_boss_warning()` |
| 300s | 生成 Boss | `_spawn_boss()` |

## 4. 镇妖碑机制

### 4.1 机制定位

镇妖碑是 v0.2 的核心地图目标，用来**打破单纯原地刷怪的循环**。

它让玩家在妖潮中做出选择：
- 继续安全刷怪
- 还是冒险靠近镇妖碑完成封印，获取额外收益

### 4.2 基础规则（v0.2 已实施）

| 字段 | 值 |
|---|---|
| 出现时机 | 关卡 ~2:00 |
| 出现位置 | 玩家附近，距离 200-280 px + jitter ±30（ed02c7e 微调）|
| 数量 | 每关 1 个（`_is_demon_seal_spawned` flag）|
| 进入封印 | 玩家进入 Area2D 范围（80 px 半径） |
| 完成时间 | 持续 8 秒 |
| 中断行为 | 玩家离开范围 → 进度暂停（不衰减，v0.2 实施） |
| 完成奖励 | 见 §4.3 |
| 完成后 | DemonSeal 消失，发出 seal_completed 信号 |

### 4.3 奖励设计（v0.2 已实施）

封印成功后，随机给予一种奖励：

- **大量修为灵珠**（约 50-100 个 XP，相当于 5-10 级）
- **立即触发一次悟道**（无需累积修为）
- **恢复部分气血**（30-50%）
- **获得短暂护盾**（5 秒无敌）
- **掉落法宝残匣**（v0.4+ 接入后给一个随机武器解锁）
- **临时提升伤害或移动速度**（30 秒 +50%）

### 4.4 风险设计（v0.2 已实施）

封印期间触发：

- **敌人刷新速度提升**（+50%）
- **纸人妖成群出现**（5-8 个）
- **一只精英怪被唤醒**（提前出场）
- **妖气区域逐渐扩大**（视觉警示）

风险持续到封印完成或玩家离开很久。

### 4.5 v0.4+ 扩展计划

- **多碑机制**：每关 2-3 碑，需要全封印才完成
- **不同碑有不同奖励 / 风险类型**
- **角色专属碑文**：孙悟空 / 哪吒 触发不同动效

## 6. 各关卡详细设计

### 6.1 L001 一·荒山古道（v0.2 已实施）

#### 主题
荒山、破庙、枯树、乱石、纸钱、旧符、游魂、鬼火。

#### 氛围
阴冷、荒凉、残破、压迫。玩家像是进入一个被妖气吞没的旧山道，四周残留着过去镇妖失败的痕迹。

#### 主要敌人
- 游魂（基础包围）
- 纸人妖（群体）
- 狐妖（高速）
- 石傀（肉盾）
- 鬼火（飘浮）
- 山魈精英

#### 关卡目标
- 在妖潮中生存 5 分钟
- 封印至少 1 座镇妖碑
- 5 分钟后击败 Boss"荒年兽"

#### Boss
荒年兽（B001），详见 [05_ENEMY_DESIGN.md](05_ENEMY_DESIGN.md) §7.4

#### 刷怪曲线
按统一节奏（§3）。

### 6.2 L002 二·幽都鬼市（v0.4 计划）

#### 主题
鬼市、灯笼、阴摊、纸钱、雾气、青绿色鬼火。

#### 氛围
阴冷市集，破灯笼摆摊，店家是鬼差。玩家穿行其中，被各色"鬼货"和摊位间的怪物追击。

#### 主要敌人（v0.4 计划）
- 灯笼鬼（自爆）
- 鬼差（远程）
- 怨婴（群体）
- 妖僧残念（光环）
- 镜妖精英

#### Boss
鬼市判官（B101），定位召唤型 + 阵地控制。

#### 关卡特色
- 视野中常出现破灯笼场景物件
- 鬼差 / 鬼僧的远程攻击逼迫玩家持续移动

### 6.3 L003 三·昆仑残境（v0.5 计划）

#### 主题
断裂阵台、浮空石、灵脉裂缝、古阵纹、残破仙阶。

#### 氛围
仙山失败的镇压留下的废墟。地面有古阵残留，玩家踩到会触发古阵效果（如减速 / 加速 / 闪烁）。

#### 主要敌人（v0.5 计划）
- 山魈（普通版）
- 蛇妖（远程）
- 黑羽妖（飘浮）
- 古阵守卫（肉盾）
- 古阵守卫精英

#### Boss
裂境山君（B201），定位阵法型 + 大范围伤害。

#### 关卡特色
- 地面有古阵图案，部分有效果（v0.5 实施）
- 浮空石可被打破，掉落特殊奖励
- 适合用元素技能（v0.5 启用五行）

## 7. 关卡 vs 角色的兼容性

| 关卡 | 推荐角色 | 不推荐 |
|---|---|---|
| 一·荒山古道 | 所有角色（均衡）| — |
| 二·幽都鬼市 | 杨戬（单体）/ 哪吒（控场） | 盘古（鬼差远程多，慢角色被风筝） |
| 三·昆仑残境 | 女娲（元素契合）/ 盘古（破阵） | 高速角色（地形复杂）|

> v0.5+ 关卡设计时为不同角色提供差异化体验。
