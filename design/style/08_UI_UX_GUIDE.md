## 1. UI 设计原则

1. **暗黑志怪风**（旧纸黄 + 朱砂红 + 黛黑）—— 详见 [07_VISUAL_STYLE_GUIDE.md](07_VISUAL_STYLE_GUIDE.md) §3.2
2. **信息密度低**，关键信息突出
3. **不遮挡核心操作区域**（角色周围视野）
4. **字体古风但可读**
5. **互动反馈明确**（hover / press / select）

## 4. 关键 UI 元素详细规范

### 4.1 气血条

| 字段 | 值 |
|---|---|
| 位置 | 屏幕底部左 |
| 长度 | 240 px |
| 高度 | 18 px |
| 颜色 | 朱砂红 (#C83232) 填充 + 旧纸黄 (#D2C3A5) 边框 |
| 文字 | 当前 / 上限（白字带阴影）|
| 更新方式 | 事件驱动（玩家 health_changed 信号）|
| 危险阈值 | < 30% 时**亮度脉冲/心跳**（非朱红边框闪烁）+ 气血数值文字始终可见。改动理由见 `art-bible §7.5 C-01`：Boss 战全局朱红下，边框朱红闪烁会被 Boss 朱红边光淹没；改用亮度脉冲与 Boss 朱红错开感知维度，并满足 `§4.5 A` 色盲数值冗余 |

## 5. HUD 状态机

```text
[启动] → [角色选择] → [入劫境] → InGame
   InGame 状态机：
     ├── 正常战斗
     ├── 升级暂停（升级面板覆盖）
     ├── Boss 预警（横幅 + 正常战斗）
     ├── Boss 战（横幅消，HUD 多 Boss 血条）
     └── 终局（道消身陨 / 封印完成）
   ↓
[再入劫境] → InGame
[退劫] → 主菜单
```

## 9. 视觉与可读性

### 9.1 重要数字规范
- 关键数字（气血、修为、伤害数字）必须用**大字号**
- 数字使用 Roboto Mono / JetBrains Mono 等宽字体

### 9.2 颜色冗余
- 颜色不仅传达信息，**配字 / 形状辅助色弱玩家**
- 例：气血红条 + "气血" 文字 + 心形小图标

### 9.3 性能
- 高频更新的标签用**事件驱动**，不每帧重绘
- HUD 用 Control 节点而非 Sprite2D
- 文字渲染缓存（Godot Theme 默认行为）

## 10. 角色专属 UI 元素

### 10.1 灵气槽（孙悟空，v0.3+）
- 位置：右上
- 形状：圆形进度环
- 中心：数字 + "灵气"二字
- 触发七十二变时：环爆光 + 玩家剪影变形动效

### 10.2 三昧真火（哪吒，v0.4+）
- 位置：右上
- 形状：火苗形进度条（垂直）
- 颜色：朱砂红 → 火橙 → 金白渐变
- 触发时：火苗向上喷发

### 10.3 天眼槽（杨戬，v0.4+）
- 位置：右上
- 形状：眼形进度条
- 颜色：青绿（充能中）→ 金光（满）
- 满时：眼睛"开"的动效

### 10.4 五色轮（女娲，v0.5+）
- 位置：右上
- 形状：五色环（金白 / 木青 / 水蓝 / 火红 / 土黄）
- 当前元素：高亮 + 中心显示元素名
- 倒计时：环边缘进度

### 10.5 开天力（盘古，v0.6+）
- 位置：右上
- 形状：方块进度条（横向）
- 颜色：黑白对比
- 倍率显示："1.5x"等数字 + 进度百分比

## 11. 可访问性预留（v0.8+）

### 11.1 字体缩放
- 设置中提供 75% / 100% / 125% / 150% 字号缩放

### 11.2 色弱模式
- 红绿色弱：替换关键红色为更橙的色（仍可区分）
- 全色弱：UI 加纹理 + 形状辅助

### 11.3 输入自定义
- 设置中允许用户自定义所有快捷键
- 支持手柄映射（v0.9+）

### 11.4 字幕 / 文本
- 所有过场文本可重看（设置中提供）
- 重要 UI 文本字号不可低于 14 px
