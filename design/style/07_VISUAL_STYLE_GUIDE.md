## 4. 剪影规范（核心视觉决策）

### 4.1 原则
- **不画具体五官** —— 玩家与敌人都是剪影
- **标志符号识别** —— 每个角色一个不可错认的小符号
- **武器剪影简化** —— 不雕花，只保留轮廓 + 颜色

### 4.2 标志符号一览

| 角色 | 标志符号 |
|---|---|
| 修行者 | 腰间铜铃剪影 + 桃木剑 |
| 孙悟空 | 头戴金色单线圆环 |
| 哪吒 | 脚下青莲底光 |
| 杨戬 | 额头第三眼（一道金色直线） |
| 女娲 | 五色光环（随元素轮换色） |
| 盘古 | 巨大体型 + 身后混沌团 |

### 4.3 敌人剪影规范

- 普通敌人：单色剪影（如游魂灰白半透）
- 精英敌人：基础剪影 + 金色边光（2-3 px 宽）+ 头顶词缀图标
- Boss：基础剪影 + 朱红边光（4-5 px 宽）+ 屏幕级体型

## 5. 特效（VFX）规范

### 5.1 优先选择
1. **GPUParticles2D**（程序粒子）—— 首选
2. **CPUParticles2D** —— 备选（不复杂场景）
3. **Sprite2D 帧动画** —— 仅在粒子无法表达时（如复杂招式）
4. **Shader** —— 仅在性能允许时（v0.6+ 美术升级阶段）

### 5.2 粒子规范

- 单个特效**最多 50 粒子**
- 粒子寿命 0.3-1.5 秒
- 颜色按 §3.1 元素色规范
- 命中反馈：60-80 粒子 + 0.2 秒淡出

### 5.3 命中反馈

| 命中类型 | 反馈 |
|---|---|
| 普通命中 | 受击单位闪白 0.1s |
| 暴击（v0.4+）| 闪白 + 短暂震屏 + 特殊粒子 |
| 精英命中 | 闪白 + 词缀色微爆 |
| Boss 命中 | 闪白 + 微震屏（防止过度刺激） |
| 击杀 | 黑烟散 + XP 球迸出 |

## 6. 字体规范

### 6.1 字体选择（v1.0 前临时占位）
- 优先**免费商用**字体
- 风格偏古风（楷书 / 隶书 / 黑体）
- 必须支持简繁中文 + 数字

### 6.2 推荐字体（占位）
- 中文主字体：**思源宋体（Source Han Serif）** —— 免费商用、古风、可读
- 中文标题字体：**汇文明朝体** 或 **方正清刻本悦宋** —— 古风强烈
- 数字字体：**Roboto Mono** 或 **JetBrains Mono** —— 数字清晰

### 6.3 字号规范

| 用途 | 字号 |
|---|---|
| HUD 大数字（气血 / 修为）| 24-28 px |
| HUD 小标签（境界 / 镇妖数）| 14-16 px |
| 升级面板技能名 | 22-26 px |
| 升级面板描述 | 14-16 px |
| 妖王预警横幅 | 36-42 px |
| 通关 / 死亡标题 | 48-56 px |
| 叙事过场文本 | 18-22 px |

### 6.4 行距
- 中文文本行距 1.5-1.8
- 数字 / 等宽文本行距 1.3

## 8. 资源命名规范

### 8.1 路径
- `res://assets/sprites/` — 精灵图
- `res://assets/vfx/` — 特效（粒子配置 / 粒子贴图）
- `res://assets/fonts/` — 字体
- `res://assets/audio/` — 音频

### 8.2 命名规则
- 文件夹 / 文件：`snake_case`
- 角色相关：`character_角色名_用途`（如 `character_sun_wukong_silhouette.png`）
- 武器相关：`weapon_武器名_用途`（如 `weapon_jingu_bang_particle.png`）
- 通用：`ui_用途` / `vfx_用途` / `audio_用途`

详见 [CODE_STYLE.md](CODE_STYLE.md)。

## 9. 占位资源处理（v0.3-v0.6）

### 9.1 占位策略
- v0.3-v0.6 阶段允许大量**色块剪影 + 程序粒子**作为占位
- 不依赖外部美术资源
- 视觉效果依靠**颜色 + 形状 + 动画**而非贴图细节

### 9.2 占位标记
所有占位资源必须明确标注 `placeholder`：

```text
res://assets/sprites/character_sun_wukong_placeholder.png
```

或在脚本中：
```gdscript
# PLACEHOLDER: 用色块剪影代替，v0.7 美术升级时替换
```

### 9.3 正式美术替换（v0.7）
- 集中处理所有占位资源
- 替换时保持视觉延续（颜色、剪影形状基本不变）
- 替换后删除 `placeholder` 标记

## 10. 原创性强约束

### 10.1 不可做的
- ❌ 不抄《黑神话：悟空》的视觉表达（如悟空写实造型 / 战斗特效风格）
- ❌ 不抄《阴阳师》的浮世绘 / 和风元素
- ❌ 不抄《王者荣耀》的国风英雄设计
- ❌ 不抄《吸血鬼幸存者》的复古像素 + 红蓝调
- ❌ 不直接使用商业字体（如方正字库未授权部分）

### 10.2 可做的
- ✅ 视觉灵感来自公共领域：古画（如明清木刻插画）、典籍插图、敦煌壁画
- ✅ 朱砂青铜、暗黑水墨等中国传统风格元素
- ✅ 神话典籍中的视觉符号（如八卦图、五行图、太极图、罗盘）

### 10.3 不确定时的判断标准
- 这个视觉元素在公共领域典籍中存在吗？→ 是 → 可用
- 这个具体表达跟某商业游戏 1:1 相似吗？→ 是 → 不可用
- 我是否在直接参考某商业作品的截图？→ 是 → 不可用，必须独立设计

## 11. 美术工作流（v0.7 美术升级阶段）

### 11.1 工作顺序
1. 玩家角色（6 个）
2. 普通敌人（v0.2 已有 5 个）
3. 精英 + Boss
4. 武器 / 法宝
5. VFX / 粒子
6. UI 元素 / 字体
7. 场景背景

### 11.2 输出格式
- 精灵：PNG 透明
- 字体：TTF / OTF
- 粒子：Godot 内置 Resource

### 11.3 风格统一检查
所有美术资源做完后，需要做一次**风格统一审视**：
- 调色板是否一致
- 剪影规范是否遵守
- 标志符号是否清晰
- 与已有 UI 是否协调
