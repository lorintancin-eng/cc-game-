## 1. 设计原则

1. 每个角色 **2-3 件标志武器**，不堆叠
2. 武器有 **6 项强化路径**（伤害、范围、冷却、数量、行为变种、终极进化）
3. 不同武器的攻击模式（目标 / 范围 / 触发方式）必须有区别
4. **数值原创**，通过本地试玩调校，不复制商业游戏
5. 优先使用 Godot `GPUParticles2D` 程序粒子，避免依赖高精度贴图

## 3. 武器基类规范

### 3.1 共享字段（基于 v0.2 `weapon_base.gd`）

```gdscript
class_name WeaponBase
extends Node

@export var weapon_id: String              # 唯一 ID，如 "wukong_jingu_bang"
@export var display_name: String           # 显示名
@export var character_owner: String        # 归属角色，用于升级池过滤
@export var element: String = "neutral"    # 五行属性（v0.4+ 启用）
@export var base_damage: float = 10.0
@export var base_cooldown: float = 1.0
@export var base_range: float = 200.0

# 强化等级
var level: int = 1
var damage_multiplier: float = 1.0
var range_multiplier: float = 1.0
var cooldown_multiplier: float = 1.0

# 当前冷却
var _cooldown_remaining: float = 0.0
```

### 3.2 共享方法

```gdscript
func _can_fire() -> bool:
    return _cooldown_remaining <= 0.0

func _fire() -> void:
    # 子类实现具体攻击逻辑
    _cooldown_remaining = base_cooldown * cooldown_multiplier

func _apply_upgrade(upgrade_id: String) -> void:
    # 应用升级，子类可扩展
    pass

func get_actual_damage() -> float:
    return base_damage * damage_multiplier

func get_actual_range() -> float:
    return base_range * range_multiplier
```

## 5. 武器详细设计

### 5.1 修行者武器（v0.2 已实装）

#### W001 追魂符（初始）
- **类型**：追踪投射
- **攻击模式**：自动锁定最近敌人，发射追踪符纸
- **范围**：屏幕内
- **数值**：damage 12 / cooldown 0.8s / 数量 1
- **强化路径**：伤害+ / 冷却- / 数量+ / 追踪速度+ / 穿透+1 / 命中后小范围溅射

#### W002 飞剑
- **类型**：方向投射
- **攻击模式**：朝最近敌人方向射出穿透飞剑
- **范围**：屏幕半径
- **数值**：damage 25 / cooldown 2s / pierce 3
- **强化路径**：伤害+ / 冷却- / 穿透+ / 飞剑数+ / 宽度+ / 回旋（返回时再次伤害）

#### W003 雷电符咒
- **类型**：范围爆发
- **攻击模式**：周期性对敌人位置落雷
- **范围**：单次落雷半径 80 px
- **数值**：damage 35 / cooldown 3s / 范围 80
- **强化路径**：伤害+ / 范围+ / 目标数+ / 冷却- / 残留雷场 / 连锁一次

#### W004 八卦阵
- **类型**：持续区域
- **攻击模式**：玩家周围旋转法阵
- **范围**：半径 150 px
- **数值**：damage_tick 5 / tick 0.5s
- **强化路径**：半径+ / 伤害+ / 旋转速度+ / 伤害频率+ / 附带减速 / 阵纹扩散

#### W005 爆裂符
- **类型**：命中爆发
- **攻击模式**：投出后命中产生范围爆炸
- **范围**：爆炸半径 60 px
- **数值**：damage 20 + 爆炸 30 / cooldown 2.5s
- **强化路径**：爆炸范围+ / 爆炸伤害+ / 溅射次数+ / 投射速度+ / 数量+ / 二段爆炸

#### W006 山河印
- **类型**：范围爆发（高冷却）
- **攻击模式**：在敌人密集区域砸落巨印
- **范围**：半径 180 px
- **数值**：damage 80 / cooldown 8s
- **强化路径**：伤害+ / 范围+ / 冷却- / 落点精度+ / 命中后眩晕 / 同时砸 2 块

### 6.2 粒子规范

- 优先 `GPUParticles2D`，避免 CPU 粒子
- 单次最多 50 粒子，超过用 `process_mode` 优化
- 持续效果（如八卦阵）用循环粒子；命中效果用 one-shot

### 6.3 命中反馈

- 受击敌人闪白 0.1s
- Boss / 精英受击有"震屏"轻微反馈
- 暴击 / 大伤害命中有更强烈特效（v0.4+ 可选）

## 7. 数值平衡基线

### 7.1 单角色满构筑 DPS

| 角色 | 期望 DPS | 主武器贡献 | 副武器贡献 |
|---|---|---|---|
| 修行者 | 600 | 40% | 60% |
| 孙悟空 | 700 | 50% | 50% |
| 哪吒 | 650 | 35% | 65% |
| 杨戬 | 550~1200（波动） | — | — |
| 女娲 | 600 | 50% | 50% |
| 盘古 | 700（开天力满） | — | — |

### 7.2 单武器贡献占比上限

任何单一武器不应超过该角色总 DPS 的 **40%**。如果某武器测试中独大，必须削弱或加强其他武器。

### 7.3 数值调校原则

- 用 qa-tester 5 分钟单局实测平均 DPS
- 调整时一次只动一个变量（damage / cooldown / range 其中之一）
- 调整后必须复测

## 9. 升级池过滤逻辑（v0.3 新增）

升级池显示规则：

```text
对每个升级项：
  if 该升级项归属"通用属性"（气血、移速、拾取等）:
      always 显示
  elif 该升级项归属某个武器:
      if 当前角色装备了该武器:
          显示对应强化项
      else:
          不显示
```

实施位置：`_get_upgrade_options()` 内。
