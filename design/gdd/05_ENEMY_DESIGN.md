## 1. 设计原则

1. 怪物不能只是血量不同，要承担**不同战斗职责**
2. 视觉差异要可读（剪影、颜色、体型一眼区分）
3. **数值原创**，不复制商业游戏曲线
4. 优先用 Godot `Resource` 配置（已实施 `resources/enemies/*.tres`）

## 2. 怪物类型分类（功能定位）

| 类型 | 战斗作用 | 视觉特征 |
|---|---|---|
| 基础包围型 | 构成基础压力 | 中等体型、慢速、群体 |
| 高速骚扰型 | 打乱走位 | 小体型、快、闪烁残影 |
| 肉盾堵路型 | 堵路压迫 | 大体型、慢、厚色 |
| 远程干扰型 | 迫使移动 | 中等体型、停止后投射 |
| 冲刺爆发型 | 制造危险瞬间 | 蓄力动作 + 冲撞 |
| 自爆压迫型 | 逼迫拉扯 | 接近后膨胀 + 爆炸 |
| 光环辅助型 | 优先击杀目标 | 周围有发光环 |
| 精英强化型 | 阶段压力 | 加金边 + 词缀图标 |
| Boss 阶段型 | 关底压力 | 屏幕级体型、血条 |

## 5. 怪物行为模式

### 5.1 基础追击（v0.1）

```gdscript
# 简化伪代码
func _physics_process(delta):
    var dir = (player.global_position - global_position).normalized()
    velocity = dir * speed
    move_and_slide()
```

### 5.2 高速骚扰（狐妖）

- 追击速度高
- 接近玩家后短暂停止（0.3s）再扑出（突进）
- 突进后冷却 1s 才能再次

### 5.3 飘浮曲线（鬼火）

- 路径不是直线，加正弦波偏移
- 接近玩家后才转直线

### 5.4 远程投射（v0.4 鬼差）

- 保持与玩家距离 250-350 px
- 周期发射"幽魂弹"（projectile）
- 玩家逼近后撤退

### 5.5 自爆（v0.4 灯笼鬼）

- 普通追击 → 进入玩家半径 60 px 触发蓄力 1s → 爆炸（damage 30，半径 80）
- 蓄力期间不可移动，可被击杀阻止爆炸

### 5.6 光环辅助（v0.4 妖僧残念）

- 自身不直接攻击
- 周围 150 px 内敌人 +30% 速度、+20% 伤害
- 死亡后光环立即消失

## 7. Boss 系统

### 7.1 Boss 出现规则

- 每关 5:00 后出现
- 4:30 屏幕中部横幅预警"妖王降临"
- Boss 出现后普通敌人**减少刷新或保持低密度**
- 玩家必须击败 Boss 才能通关

### 7.2 Boss 设计模板（通用）

每个 Boss 应有：

- **4-5 个技能**（含蓄力技 / AOE / 召唤 / 暴怒）
- **每个技能有可读预警**（红圈 / 蓄力光效 / 屏幕震动）
- **受伤反馈**（闪白 + 震屏）
- **低血暴怒阶段**（30% 血量以下）
- **死亡反馈**（黑屏 + 慢动作 + 封印完成）

### 7.4 B001 荒年兽（v0.2 已实施）

#### 定位
冲撞型 Boss，强调压迫、位移和区域预警。

#### 背景设定
荒年兽由灾荒、旧岁怨火和断裂香火凝成。**它不是传统年兽**，而是山海劫境中吞食香火、招来灾厄的妖王。

#### 外观方向
- 黑红兽影
- 断角
- 背负残破灯笼
- 身上有纸灰和火星
- 移动时脚下留下焦痕

#### 技能设计

| 技能 | 效果 | 预警 |
|---|---|---|
| 灾厄冲撞 | 短暂蓄力（0.8s）后向玩家方向直线冲刺 | 蓄力红光 + 方向线 |
| 怨火爆裂 | 地面出现红圈（3 个），1s 后爆炸 | 红圈预警 |
| 吞香召妖 | 召唤 3 纸人妖 + 2 游魂 | 屏幕中部"吞香召妖"文字 |
| 年火环 | 释放一圈向外扩散的火焰，玩家须躲到环外 | 自身朱红蓄力光 |
| 暴怒 | 血量 < 30% 后速度 +50%、攻击频率 +50% | 黑红光环爆发 |

#### 数值

| 字段 | 值 |
|---|---|
| HP | 3000 |
| 移速 | 80（基础）/ 120（暴怒） |
| 攻击间隔 | 5s（基础）/ 3.3s（暴怒） |
| 体积 | 2.5x（普通敌人） |
