## 1. 游戏定位

**中国神话暗黑志怪风的闯关式 Roguelite 生存游戏。**

玩家在每一关 5 分钟的妖潮试炼中：
1. 通过移动走位躲避敌人
2. 自动释放法术 / 法宝伤害敌人
3. 吸收修为提升境界
4. 通过"悟道"逐步解锁与强化技能
5. 第 2 分钟左右出现镇妖碑，可冒险封印获取额外收益
6. 5 分钟后迎战关底妖王（Boss）
7. 击败妖王后完成劫境封印，进入下一关

详细愿景见 [game-concept.md](game-concept.md)。

## 2. 核心设计原则

### 2.1 每关目标明确

不采用无限生存模式，而采用**闯关模式**。每一关都有明确的：
- 时间目标（5 分钟）
- 中期目标（封印镇妖碑）
- 终局目标（击败 Boss）

### 2.2 技能通过升级逐步解锁

玩家**不应该开局拥有所有技能**。每一局开始时只有该角色的基础技能。随着击杀敌人 → 吸收修为 → 提升境界，在"悟道"三选一中逐步解锁与强化。

详见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §9 升级池过滤逻辑。

### 2.3 暗黑志怪风格优先

整体表现不走明亮可爱国风，而走**暗色、压迫、阴冷、志怪、镇妖、修行**的视觉与内容方向。

详见 [07_VISUAL_STYLE_GUIDE.md](07_VISUAL_STYLE_GUIDE.md)。

### 2.4 地图必须有目标点

加入"**镇妖碑**"机制，让玩家不只是原地绕圈刷怪，而是需要在妖潮压力下做出**风险收益选择**。

详见 [06_LEVEL_DESIGN.md](06_LEVEL_DESIGN.md) §4。

### 2.5 构筑要有流派感

技能不只是数值不同，而要形成**不同玩法流派**：

- **符法系**：追踪、爆裂、封印
- **剑修系**：穿透、直线、回旋
- **雷法系**：范围爆发、多目标落雷
- **阵法系**：护体、控场、持续伤害
- **法宝系**：大范围、特殊机制、高冷却高收益
- **召唤系**：独立 AI 单位（v0.3+）

详见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §2.2。

### 2.6 数据驱动迭代

敌人数值、武器行为、升级、波次、掉落优先通过 **Godot Resource** 或结构化数据配置，避免硬编码大型表。

详见 [ARCHITECTURE.md](ARCHITECTURE.md) §数据驱动设计。

## 3. 玩家行为契约

| 行为 | 触发 | 备注 |
|---|---|---|
| 移动 / 躲避 | 手动（WASD / 方向键） | 持续输入 |
| 攻击 / 释放技能 | 自动 | 按冷却 + 目标规则触发 |
| 拾取修为 | 自动 | 进入拾取半径 |
| 升级选择 | 手动（鼠标 / 1/2/3） | 暂停三选一 |
| 进入镇妖碑 | 手动（移动进入范围） | 自动开始封印 |
| 重新开始 | 手动（Enter / 鼠标） | 死亡 / 通关后 |

## 4. 核心玩法循环（单关）

```
开始关卡
   ↓
角色初始技能自动释放 + 玩家走位躲避
   ↓
击杀敌人 → 掉落修为灵珠
   ↓
拾取修为 → 修为条增长
   ↓
修为满 → 暂停 → 悟道三选一
   ↓
选择后 → 恢复战斗（新技能 / 强化生效）
   ↓
（约 2:00）镇妖碑出现 → 玩家选择是否冒险封印
   ↓
（封印期间）刷怪压力提升 → 完成后获奖励
   ↓
（约 3:00-4:30）精英怪出现 → 阶段压力
   ↓
4:30 妖王降临预警
   ↓
5:00 Boss 出现 → 击败
   ↓
封印完成 → 通关 / 进入下一关
```

详细关卡节奏曲线见 [06_LEVEL_DESIGN.md](06_LEVEL_DESIGN.md) §3。

## 6. 技能与升级系统

### 6.1 升级三选一

每次境界提升（达到等级阈值），暂停游戏并展示三个升级选项。选项分四类：

1. **解锁** — 新技能
2. **强化** — 已有技能的属性提升
3. **属性** — 玩家通用属性（气血、移速、拾取等）
4. **进化**（v0.6+）— 技能升级到 Lv5 后的质变

### 6.2 升级池按角色过滤（v0.3 新机制）

```text
对每个升级项：
  if 该项属于"通用属性":
      always 显示
  elif 该项属于某武器：
      if 当前角色装备了该武器:
          显示对应强化项
      else:
          不显示
```

详见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §9。

## 8. 镇妖碑机制

每局 ~2:00 生成 1 个镇妖碑。玩家进入范围封印 8 秒，完成获奖励，封印期间有风险事件。

## 10. 战斗数据约定

### 10.1 伤害类型

- **直接伤害**（damage 字段）：武器命中即时伤害
- **持续伤害**（damage_tick + tick_rate）：周期性伤害（如八卦阵）
- **爆炸伤害**（explosion_damage + explosion_radius）：命中后范围
- **灼烧**（burn_dps + burn_duration）：留地面持续

### 10.2 受伤反馈

- 敌人受击闪白 0.1s
- 精英 / Boss 加震屏微反馈
- 暴击 / 大伤害额外特效（v0.4+ 可选）

### 10.3 死亡处理

- 普通敌人 hp ≤ 0 → 死亡动画 + XP 掉落 + queue_free
- 精英 → 加奖励掉落
- Boss → 触发通关流程（封印完成）

## 11. 单局结算

| 状态 | 触发 | 后续 |
|---|---|---|
| 道消身陨 | 玩家 hp ≤ 0 | 显示死亡结算，可"再入劫境" |
| 封印完成 | 击败 Boss | 显示通关结算，进入下一关（v0.4+）/ 主菜单 |
| 主动退出 | ESC → 退劫 | 回主菜单 |

## 12. 数值平衡参考基线

| 阶段 | 期望表现 |
|---|---|
| 0:00-1:00 | 玩家熟悉，无死亡风险 |
| 1:00-2:00 | 第一次接近气血危险，靠操作躲避 |
| 2:00-3:00 | 镇妖碑出现，玩家面临风险收益选择 |
| 3:00-4:30 | 精英压力，构筑成熟玩家应能稳定推进 |
| 4:30-5:00 | 妖王预警，玩家做最终准备 |
| 5:00+ | Boss 战，玩家应有 5-8 个解锁/强化 |
| 通关时间 | 5:30-6:30（含 Boss 战） |

各角色满构筑 DPS 目标见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §7.1。

## 13. 性能预期

- 屏幕同时存在 50-100 敌人 / 200+ 投射物
- 目标 60 FPS 稳定
- 极限情况（Boss + 召唤）允许短暂降至 30 FPS

详见 [ARCHITECTURE.md](ARCHITECTURE.md) §性能方向。
