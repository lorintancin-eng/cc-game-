# 哪吒技能重设计 ·「莲花化身 · 三头六臂」(Quick Design Spec)

> 状态：`[设计中→实现中]` — 2026-05-31
> 起因：玩家反馈「哪吒技能太单调，玩起来不够爽」。原版三昧真火＝受击攒槽→下一击 +30%，
> 太被动、payoff 太小、武器各自为战、升级全是干数值。
> 目标：把哪吒改成 **爽感驱动**——蓄力→爆发循环 + 武器联动 + 构筑型升级。
> 取代：原 `design/narrative/02_CHARACTER_DESIGN.md §4.3` 的三昧真火「下一击增强」机制。

---

## 1. 设计支柱（爽点来源）

| 支柱 | 机制 | 为什么爽 |
|---|---|---|
| **蓄力→爆发循环** | 三昧真火攒满 → 法相天地 6s 全面强化 → 莲花真火爆收尾 | 周期性力量高峰，越打越强，有「攒大招」的期待与释放 |
| **打得越凶攒越快** | 击杀 +5、受击 +8 充能 | 充能来自战斗本身（爽），不再只靠挨打（憋屈） |
| **武器联动** | 三才合击：乾坤圈出手额外甩火尖枪 | 武器不再各自为战，有 combo 连锁感 |
| **构筑型升级** | 万箭/双圈/环天/牵引/法相延绵… 改变玩法而非只加数值 | 每次升级是「选构筑」，不是「数字 +8」 |

## 2. 三昧真火（充能槽，重做）

| 字段 | 值 |
|---|---|
| 上限 | 100 |
| 充能 | **击杀 +5**；**受击 +8** |
| 满槽 | 标记 ready，**待玩家按 1 主动释放**（不自动；攒满后可留到关键时机放） |
| HUD | 复用现有能量条（`current_lingqi`）；满时显示「★ 按 1 释放 ★」+ 金光脉冲 |

## 3. 法相天地（Avatar Mode，核心爽点）

三昧真火满后按 **1** 主动释放（`Nezha.try_activate_avatar()`），持续 **6 秒**，期间：

| 效果 | 值 |
|---|---|
| 全武器射速 | **×2.5**（冷却 ×0.4） |
| 全武器伤害 | **×1.5** |
| 火尖枪 | 变 **三枪扇形齐射** |
| 自身减伤 | **−30%**（鼓励猛攻、爆发即生存窗口） |
| 视觉 | 哪吒放大 ×1.4 + 火焰光环（占位，美术后续） |

**结束瞬间 → 莲花真火爆（nova）**：以玩家为心、半径 **160** 的范围爆发，
伤害 = **80 + 8 × 法相期间击杀数**（打得越多炸得越狠）。
随后三昧真火清零，重新蓄力。

## 4. 三才合击（synergy，三武器全解锁后）

乾坤圈**每次出手**额外朝次近敌甩出一道**迷你火尖枪**（50% 伤害、无灼烧地面）。
武器联动的连锁感；解锁第三件武器后明显变强。

## 5. 武器组合（投射物行为不变，新增构筑选项）

- **火尖枪 W201**：穿透火枪 + 灼烧地面（不变）
- **乾坤圈 W203**：自动锁定回旋两段（不变）
- **混天绫 W202**：束缚/Boss减速/DoT 领域（不变）

## 6. 升级树（构筑型，替代干数值）

> 复用现有 D-B2 堆叠上限框架。`*_damage` cap 3，`unlock_*` cap 1，构筑型(toggle)cap 1。

**火尖枪**
- 烈焰 +8（damage，cap3）
- **万箭齐射**（常驻 +1 枪，最多 +2，cap2）
- **燎原**（灼烧地面半径×1.6 + 时长×1.5，cap1）

**乾坤圈**（解锁后）
- 镇煞 +8（damage，cap3）
- **双圈**（每次 +1 枚回旋圈，cap2）
- **环天圈**（乾坤圈进化：改为**指向最近敌人 + 在多个敌人之间弹射**的回旋圈；**每级 +1 发**，最多 +3 → 满级时满屏金圈乱弹）

**混天绫**（解锁后）
- 赤练 +3（每跳 DoT，cap3）
- **缚天大阵**（领域半径×1.4 + 时长 +2s，cap1）
- **牵引**（toggle：领域把敌人拉向中心，聚怪，cap1）

**法相天地**
- **真火不灭**（充能 +25%，cap3）
- **法相延绵**（法相 +1.5s，cap2）
- **怒火焚天**（莲花爆伤害 +40%，cap2）

**解锁项**：悟得乾坤圈 / 悟得混天绫（cap1，开局锁定，升级解锁）。

## 8. 关键实现笔记

- **充能**：`_on_kill`（已接 EnemySpawner.enemy_killed 转发）+5；`_on_damaged`（已接 player.take_damage 转发）+8。无需新管线。
- **法相计时**：Nezha 加 `_physics_process` 跑 6s 计时；到期触发 nova + 清零。
- **武器法相增益**：NezhaWeaponBase 覆盖 `_get_cooldown()`（法相 ×0.4）+ `_attack_boost()`（法相返回 dmg×1.5）。武器自动变快变强。
- **减伤**：player.take_damage 查 `_character_base.get_incoming_damage_mult()`（默认 1.0；Nezha 法相返回 0.7）。同 `_on_damaged` 的小 hook。
- **nova**：Nezha 不是 Node2D；以 `get_parent().global_position`（Player 位）为心，迭代 enemies group + 距离 + take_damage。占位无视觉（美术后补）。
- **冻结约束**：仍只调 enemy 公共 API（take_damage / velocity），不碰 enemy.gd。
- **测试**:三昧真火充能/满槽/法相计时/减伤/nova 伤害 走纯逻辑单测；法相期间武器增益 + 解锁 + 升级走 Main.tscn 集成测试。
