# 02 角色设计（Character Design）

> 状态：`[完整]` — Phase 3 内容已补全
> 来源：基于 archive/v0.3/V0_3_CHARACTERS.md 扩展，整合修行者代码总结与所有神祇预案

---

## 1. 设计原则

1. 每个角色 = **独特玩法变种**，不是数值差异
2. 每个角色有**专属能量条** + 2-3 件标志武器
3. 视觉走"暗黑志怪 + 剪影"风（详见 [07_VISUAL_STYLE_GUIDE.md](07_VISUAL_STYLE_GUIDE.md)）
4. 所有人物源自**公共领域典籍**（《西游记》《封神演义》《山海经》《淮南子》等明清及更早作品）
5. 不复制任何商业游戏对相同人物的视觉、技能、命名表达

### 4.1 C00 修行者（Cultivator）— v0.1 已实装

#### 神话来源
凡间求道者，非特定神话人物。代表无特殊出身的修行人，作为玩家的"序章"身份。

#### 游戏内身份
**「驱邪人」**。最早进入山海劫境的凡人，靠累代相传的符箓与法宝对抗妖潮。

#### 视觉方向
- 黛灰色剪影 + 朱砂披帛
- 不画五官，腰间悬挂铜铃 / 桃木剑剪影
- 战斗时脚下浮现淡黄符纸圈

#### 流派定位
**符法系 / 通用基准**（其他角色平衡参考他）

#### 基础属性

| 属性 | 值 | 备注 |
|---|---|---|
| 气血上限 | 100 | 基准 |
| 移速 | 200 | 基准 |
| 拾取半径 | 50 | 基准 |

#### 专属能量
无（v0.2 设计未引入能量条机制，保留作为对照组）

#### 武器组合（v0.2 已实装 6 件）

| 武器 ID | 名称 | 流派 | 状态 |
|---|---|---|---|
| W001 | 追魂符 | 符法（追踪） | 初始装备 |
| W002 | 飞剑 | 剑修（穿透） | 升级解锁 |
| W003 | 雷电符咒 | 雷法（范围） | 升级解锁 |
| W004 | 八卦阵 | 阵法（持续区域） | 升级解锁 |
| W005 | 爆裂符 | 符法（命中爆发） | 升级解锁 |
| W006 | 山河印 | 法宝（高冷却 AOE） | 升级解锁 |

详细数值与强化路径见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §5.1。

#### 设计意图
- 作为 v0.1 MVP 角色，验证完整游戏循环
- 提供完整的"符法 + 剑修 + 雷法 + 阵法 + 法宝"五大流派起点
- 玩家可在升级中自选构筑方向
- 作为后续神祇平衡的基准（其他角色 DPS 应与之相近，±15%）

### 4.2 C01 孙悟空（Sun Wukong）— v0.3 设计完成

#### 神话来源
《西游记》（公共领域，吴承恩，明代）。关键元素：金箍棒（如意金箍棒）、七十二变、毫毛分身、火眼金睛。

#### 游戏内身份
**「弼马温」** —— 自嘲式称号，符合 v0.2 暗黑志怪感。

**定位**：混战之王，越乱越强。最强 AOE 选手，不擅长单体高血量。

#### 视觉方向（原创表达）
- 黑红剪影 + 头戴**金色单线圆环**（不画毛发、面部）
- 金箍棒剪影显示为简化棍棒（避免雕花细节）
- 七十二变形态：**青烟 + 小猴/鸟/鱼等小型剪影**
- 战斗时脚下浮现淡红云纹（区别于哪吒的青莲、女娲的五色环）

#### 流派定位
**近身旋转 + 突刺 + 召唤**（混战之王）

#### 基础属性

| 属性 | 值 | 与修行者对比 |
|---|---|---|
| 气血上限 | 100 | 持平 |
| 移速 | 230 | +15% |
| 拾取半径 | 60 | +20% |

#### 专属能量：灵气

| 字段 | 值 |
|---|---|
| 最大值 | 30 |
| 充能方式 | 击杀普通敌人 +1，精英 +5，Boss 不触发 |
| 触发方式 | 满 30 **自动**触发「七十二变」 |
| 效果（3 秒内） | 伤害 +50%、移速 +30%、**敌人无法选定为攻击目标（无敌）** |
| 视觉表现 | 玩家剪影变成小猴剪影 + 青烟环绕 |
| 触发后 | 灵气清零 |

**HUD 显示**：右上角圆形进度环，满 30/30 时金色高亮 + 微弱脉冲特效。

#### 武器组合

详细数值与强化路径见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §5.2。

| 武器 ID | 名称 | 类型 | 解锁 |
|---|---|---|---|
| W101 | 如意金箍棒 | 近身旋转（持续生效） | 初始装备 |
| W102 | 金箍棒·变长 | 方向性突刺（屏幕级） | 升级解锁 |
| W103 | 毫毛分身 | 召唤投射物（小猴自爆） | 升级解锁 |

#### 设计意图
- **金箍棒** vs v0.2 八卦阵：相似的近身旋转，但金箍棒范围更小（90 vs 150）、DPS 更高、**强迫贴脸**
- **金箍棒·变长** vs v0.2 飞剑：都是穿透方向技，但变长是**屏幕级 + 击退**，且只朝玩家朝向
- **毫毛分身** vs v0.2 山河印：都是高冷却 AOE，但毫毛是**分散自爆 + 主动出击**，山河印是单点砸落
- **七十二变** 的"3 秒无敌"机制：让玩家在混战中通过击杀获得喘息，符合"越乱越强"定位

### 4.3 C02 哪吒（Nezha）— v0.4 计划

#### 神话来源
《封神演义》《西游记》（公共领域）。剔骨还父、莲花化身、火尖枪 / 混天绫 / 乾坤圈三宝。

#### 游戏内身份
**「火劫童子」**。最早下凡的少年神祇，性烈如火，三件神兵围身而战。

#### 视觉方向
- 暗红色剪影 + 青莲底光
- 朱砂火纹环绕身体
- 战斗时脚下浮现一朵青莲底盘

#### 流派定位
**多武器立体覆盖**（同时有近战 / 投射 / 控场，是技能数最多的神祇）

#### 基础属性

| 属性 | 值 | 与修行者对比 |
|---|---|---|
| 气血上限 | 90 | 略低 |
| 移速 | 220 | 略快 |
| 拾取半径 | 55 | 略大 |

#### 专属能量：三昧真火

| 字段 | 值 |
|---|---|
| 最大值 | 100 |
| 充能方式 | 受到伤害时 +10 火 |
| 触发方式 | 火满后，**下一次**攻击触发增强 |
| 效果（单次） | 所有武器范围 +50%、伤害 +30%，触发后火清零 |
| 战略 | 少受伤少触发，多受伤多爆发 → 风险收益 |

#### 武器组合

| 武器 ID | 名称 | 类型 | 解锁 |
|---|---|---|---|
| W201 | 火尖枪 | 方向性投射 + 灼烧地面 | 初始装备 |
| W202 | 混天绫 | 范围束缚 + 持续伤害 + 减速 | 升级解锁 |
| W203 | 乾坤圈 | 自动锁定 + 回旋两段 | 升级解锁 |

**进化项「三才合击」**：三件武器全部解锁后，乾坤圈命中会原地召唤一道火尖枪 + 迷你混天绫（30% 伤害，无叠加上限）。

### 4.4 C03 杨戬（Yang Jian）— v0.4 计划

#### 神话来源
《西游记》《封神演义》（公共领域）。三尖两刃刀、天眼、哮天犬、八九玄功。

#### 游戏内身份
**「二郎真君」**。冷峻判官，单点高伤 + 召唤宠物，长于猎杀强敌。

#### 视觉方向
- 银白剪影 + **第三眼位置一道金色直线**（不画完整面部）
- 三尖两刃刀剪影背后悬浮
- 哮天犬：黑色幼狼剪影 + 绿色双瞳

#### 流派定位
**单体爆发 + 召唤**（精英 / Boss 杀手）

#### 基础属性

| 属性 | 值 | 与修行者对比 |
|---|---|---|
| 气血上限 | 110 | 高 |
| 移速 | 190 | 略慢 |
| 拾取半径 | 45 | 略小 |

#### 专属能量：天眼槽

| 字段 | 值 |
|---|---|
| 最大值 | 100 |
| 充能方式 | 战斗中每秒 +2，击杀小怪 +3，击杀精英 +30 |
| 触发方式 | 满 100 后，**下一次**三尖两刃刀变为"开天眼一斩" |
| 效果 | 对小怪即死；对精英 / Boss 造成 4 倍伤害 |
| 战略 | 可手动留蓄等关键时机 |

#### 武器组合

| 武器 ID | 名称 | 类型 | 解锁 |
|---|---|---|---|
| W301 | 三尖两刃刀 | 近战三段斩（朝向 90° 扇形） | 初始装备 |
| W302 | 哮天犬 | 召唤宠物（自主追击 + 减速） | 升级解锁 |
| W303 | 天眼真火 | 全屏锁定最低血敌人激光 | 升级解锁（等级 ≥ 3） |

### 4.5 C04 女娲（Nvwa）— v0.5 计划

#### 神话来源
上古神话（《淮南子》《山海经》等公共领域文献）。补天五色石、造人、化育万物。

#### 游戏内身份
**「补天娘娘」**。唯一带治疗机制的神祇，五行循环输出。

#### 视觉方向
- 五色光环剪影（金白 / 木青 / 水蓝 / 火红 / 土黄轮换）
- 不画人形面部，只有光团 + 飘带 + 五色丝
- 战斗时身后悬浮一块**巨大的破碎五色石**

#### 流派定位
**元素循环 + 自疗 + 阵地战**（不擅长机动，需要选好位置打阵地）

#### 基础属性

| 属性 | 值 | 与修行者对比 |
|---|---|---|
| 气血上限 | 80 | 低 |
| 移速 | 180 | 慢 |
| 拾取半径 | 70 | 最大 |

#### 专属能量：造化（独特机制）

不是普通充能槽，而是 **五色轮**：每 4 秒自动切换一次元素属性（金→木→水→火→土→金...）

| 元素 | 效果（改变所有技能） |
|---|---|
| 金 | 所有伤害 +20% |
| 木 | 每秒回 2 血 |
| 水 | 技能减速效果 +50% |
| 火 | 所有技能附加灼烧 |
| 土 | 受到伤害 -25% |

**HUD 显示**：当前元素 + 下一个元素 + 倒计时，玩家根据元素调整走位策略。

#### 武器组合

| 武器 ID | 名称 | 类型 | 解锁 |
|---|---|---|---|
| W401 | 补天石 | 天降单点（五色随机） | 初始装备 |
| W402 | 五色丝 | 脚下持续区域（随玩家移动） | 升级解锁 |
| W403 | 造人术 | 召唤短期分身 | 升级解锁（等级 ≥ 3） |

### 4.6 C05 盘古（Pangu）— 终极解锁

#### 神话来源
上古神话（盘古开天辟地，公共领域）。开天斧、阴阳二气、化身万物。

#### 游戏内身份
**「开天者」**。终极解锁，反流派 —— 极慢但极强，每一击毁天灭地。

#### 视觉方向
- **巨大灰黑剪影**（玩家模型比其他神祇大 30%）
- 身后浮现混沌团（黑白旋转）
- 开天斧剪影占屏幕显著比例

#### 流派定位
**蓄力爆发 · 反高频**（颠覆游戏节奏。其他角色 1.2~3s 一次攻击，盘古 6~15s 一次）

#### 基础属性

| 属性 | 值 | 与修行者对比 |
|---|---|---|
| 气血上限 | 200 | 最高 |
| 移速 | 140 | 最慢 |
| 拾取半径 | 80 | 最大 |
| 体型 | 1.3x | 碰撞 hitbox 也大 |

#### 专属能量：开天力

| 字段 | 值 |
|---|---|
| 最大值 | 100 |
| 充能方式 | 每秒 +1（被动） |
| 消耗方式 | **任何武器攻击会消耗对应开天力**（武器越强消耗越多） |
| 影响 | 开天力越满，武器伤害**越高**（线性 1.0x ~ 2.5x） |
| 战略 | 等满再放，一击秒怪；强迫玩家学会拉扯走位扛压 |

#### 武器组合

| 武器 ID | 名称 | 类型 | 解锁 |
|---|---|---|---|
| W501 | 开天斧 | 超大十字斩（屏幕级） | 初始装备 |
| W502 | 阴阳二气 | 双向追踪光球（阴减速 + 阳灼烧 + 合击额外伤害） | 升级解锁 |
| W503 | 开辟 | 全屏清场（最终大招，需满 100 开天力） | 升级解锁（等级 ≥ 5） |

## 6. 角色平衡基线

### 6.1 期望 DPS 对比

| 角色 | 5 分钟满构筑期望 DPS | 备注 |
|---|---|---|
| 修行者（v0.1 基准） | ~600 | 平衡基线 |
| 孙悟空（v0.3） | ~700 | +15%，因移速高、混战收益强 |
| 哪吒（v0.4） | ~650 | 风险触发型，波动大 |
| 杨戬（v0.4） | ~550 普通 / ~1200 触发 | 单体爆发，波动极大 |
| 女娲（v0.5） | ~600（五行轮换均摊） | 元素加成均摊后 |
| 盘古（v0.6） | ~700（开天力满时）| 蓄力时低，释放时极高 |

### 6.2 平衡策略

- 任何角色满构筑 DPS 应在 **±15%** 范围内
- 单角色独大不允许（如某角色 1.5 倍于其他）
- 平衡通过 qa-tester 实测 5 分钟单局对比验证
