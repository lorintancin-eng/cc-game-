## 1. 版本号语义

采用 [Semantic Versioning](https://semver.org/) 简化版：

- `MAJOR.MINOR.PATCH`
- v0.x：内部测试 + 持续添加功能
- v1.0：首次公开发布
- 1.x：大版本扩展

例：v0.2.1 = 在 v0.2 基础上的 bugfix；v0.3 = 新角色系统大功能。

## 4. 跨版本依赖

```
v0.2 完成 → v0.3 (角色系统在 v0.2 基础上)
v0.3 完成 → v0.4 (新神祇基于角色框架)
v0.5 必须启用元素系统 → v0.6 进化项依赖元素
v0.7 美术升级与功能开发并行不冲突
v0.8 存档系统应在 v0.6 角色全部完成后实施（避免重构）
```

## 5. 优先级原则

- **P0 必做**：核心循环 / 关卡推进 / 已承诺的神祇
- **P1 应做**：平衡 / 美术 / 性能
- **P2 可选**：高级功能（局外成长 / 多角色编队）
