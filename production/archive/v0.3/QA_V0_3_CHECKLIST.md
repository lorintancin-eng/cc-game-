## 测试前准备

1. 用 Godot 编辑器打开 `D:/game/game` 项目。
2. 确认编辑器底部 Output 面板无红色 push_error。
3. 确认 FileSystem 面板中存在以下场景文件：
   - `scenes/Main.tscn`
   - `scenes/player/Player.tscn`
   - `scenes/ui/HUD.tscn`
   - `scenes/ui/LevelUpPanel.tscn`
   - `scenes/ui/GameOverPanel.tscn`

   若为空，角色选择无法进入游戏（阻塞级别）。
5. 所有测试均从 `scenes/Main.tscn` 按 F5 启动。

## 1. Player（修行者 + 孙悟空双角色）

### 1A. 修行者（Cultivator）

**启动方式**：F5 → 角色选择面板 → 点击"修行者"按钮

**操作步骤**：
1. 用 WASD 持续移动 30 秒，测试上下左右、斜向。
2. 站立不动 5 秒，确认玩家不会自行漂移。
3. 贴近敌群，承受 3 次伤害。
4. 存活至第一次升级（约 60-120 秒）。
5. 在升级面板期间尝试移动，确认移动暂停。
6. 选择升级后继续战斗。
7. 让玩家死亡。

**预期**：
- 移动平滑、无卡顿瞬移；速度对应修行者基础 180
- 气血 HUD 实时减少；减到 0 触发死亡
- 升级面板弹出后计时暂停
- 死亡显示"道消身陨"结算

**修行者专项检查**：
- [ ] HUD 中**不出现**灵气能量条
- [ ] 攻击武器为追魂符（不应有金箍棒旋转）

**失败判定**：无法移动 / HUD 不更新 / 出现灵气条 / 红色脚本错误

### 1B. 孙悟空（Sun Wukong）

**启动方式**：F5 → 角色选择面板 → 点击"弼马温（孙悟空）"按钮

**操作步骤**：
1. 进入游戏，观察孙悟空外观（金黄色 Body，与修行者青色区分）。
2. 移动 20 秒，确认体感速度比修行者快（230 vs 180）。
3. 承受伤害 3 次。
4. 观察经验球吸取距离（60 vs 50，距离更远即被吸引）。
5. 死亡测试。

**预期**：
- 孙悟空 Body 颜色明显不同（金黄）
- 移速明显快于修行者
- 经验球吸取范围更大
- 死亡流程正常

**失败判定**：与修行者无差异 / 速度异常 / 死亡报错

## 3. Weapon（武器验证）

### 3A. 修行者武器（6 件）

依次升级解锁追魂符 / 飞剑 / 雷电符咒 / 八卦阵 / 爆裂符 / 山河印，每件验证：
- 自动攻击触发
- 命中扣血
- 强化后效果增强

**总体失败判定**：已解锁武器无攻击动作 / 伤害为 0 / 解锁后面板仍显示"悟得"选项

### 3B. 孙悟空武器（3 件）

**选孙悟空测试**

#### W101 如意金箍棒（初始）

1. 进入游戏，不升级，等待 10 秒
2. 观察玩家周围金色线段持续顺时针旋转（90 px 半径）
3. 金箍棒扫过敌人，确认扣血 10
4. 同一敌人 0.5s 内不重复受伤

**预期**：旋转可见 / 接触扣血 / 防多重命中生效

#### W102 金箍棒·变长（升级解锁）

1. 触发升级，选"金箍棒·变长"（ID: `wukong_jingu_bang_extend`）
   **若面板无此选项**：立即记录为阻塞 bug（FU-03 follow-up）
2. 等待 4 秒，观察突刺视觉（朝最近敌人，宽 40px 长 600px 金色线段，0.15s 后消失）
3. 验证击退（敌人被推开 80px）

**已知风险（不阻塞通关）**：`dir.length_squared() < 0.000001` 在 normalize 后是死代码

**失败判定**：从未出现突刺视觉 / 敌人不扣血 / 击退不触发 / 每帧都触发突刺

#### W103 毫毛分身（升级解锁）

1. 触发升级，选"毫毛分身"（ID: `wukong_hair_clone`）
2. 等待 8 秒
3. 观察 3 个白色小三角分身，朝不同方向飞出
4. 分身碰敌后爆炸（半径 70px，damage 25）
5. 未碰到敌人的分身 6 秒后安静消失（不爆炸）

**已知风险（FU-05）**：parent==null 时 `_try_attack` 仍 return true 烧冷却 —— 测试场景下 parent 是 current_scene，应不会触发

**失败判定**：分身不生成 / 不移动 / 爆炸无伤害 / 分身随玩家移动

## 5. UI（HUD 灵气条 + 角色选择面板）

### 5A. 角色选择面板

1. F5 启动 Main.tscn
2. 面板内容：标题"择神而行" + "弼马温（孙悟空）" + "修行者" 两按钮

5. 点击"修行者" → 面板消失 → 修行者出现 → HUD 无灵气条
