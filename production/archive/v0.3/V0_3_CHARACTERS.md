# MythSurvivor v0.3 角色设计文档 — 神祇下凡

## 0. 文档元信息

- 版本：v0.3 设计草稿（待用户最终评审）
- 上游依赖：[core_gameplay_v_02.md](core_gameplay_v_02.md)、[GDD.md](GDD.md)、[ARCHITECTURE.md](ARCHITECTURE.md)
- 实施范围：本次 v0.3 优先实现「孙悟空」单一角色 + 角色选择框架。其他神祇详见 §6 附录，留待 v0.4+ 实施。
- 原创性约束：所有人物形象来自中国公共领域神话典籍（《西游记》《封神演义》《山海经》《淮南子》等明清及更早作品）。视觉、技能机制、命名风格、数值平衡**不得复制任何商业游戏**对相同人物的表达。

## 1. 设计范围

### 1.1 v0.3 必做范围

1. **角色基类**与角色选择系统（解耦"玩家身份"与"玩家技能"）
2. **孙悟空**完整实现：3 件武器、专属能量条「灵气」、独立升级池
3. **默认角色变更**：开局默认角色由「修行者」改为「孙悟空」
4. **升级池过滤**：当前角色不持有的技能不出现在悟道选项
5. **修行者保留**：作为可选角色（不删除 v0.2 已有技能与场景）

### 1.2 v0.3 暂不做

- 哪吒、杨戬、女娲、盘古的实现（仅设计稿，见 §6）
- 五行相克系统（机制设计已写入 §4.3，留待 v0.3.5 或 v0.4）
- 局外永久成长（神祇等级 1~10）
- 角色解锁条件门控（v0.3 默认全角色解锁，简化测试）

## 2. 故事背景与世界观融合

### 2.1 设定起源（新增）

```
鸿蒙未开之时，盘古开天，元气分阴阳。
万年前，山海封印妖王，天地各得安宁。
今日，封印「山海劫境」崩裂，妖潮逆涌人间。
上古神祇遂分别下凡，入劫境镇压妖王，重立封印。
```

「山海劫境」是 v0.2 已立下的设定，本文档赋予它**起源**：盘古时代封印的妖王封印崩裂，神祇必须分别下凡重立封印。

### 2.2 玩家身份的演化

| 阶段 | 玩家身份 | 实施版本 |
|---|---|---|
| v0.2 序章 | 凡间修行者 | 已实现，本次保留为可选 |
| v0.3 觉醒 | 孙悟空（齐天大圣） | **本版本主推** |
| v0.4 应劫 | 哪吒、杨戬 | 后续 |
| v0.5 创世 | 女娲 | 后续 |
| 终章 | 盘古 | 终极解锁 |

### 2.3 与 v0.2 暗黑志怪基调的一致性

神祇下凡不削弱 v0.2 的「暗黑、压迫、镇妖、修行」气质。所有神祇的视觉表达都遵循 v0.2 已立下的：

- 黑红水墨剪影
- 朱砂青铜符纹
- 角色不画具体五官，以**剪影 + 标志符号**识别（避免与商业游戏形象重叠）
- 法宝以**程序化粒子**表达，不依赖高精度美术

## 3. 主框架

### 3.1 元游戏结构

```
主菜单
  ├── 角色选择                ← v0.3 新增
  │     ├── 孙悟空（默认）
  │     └── 修行者（v0.2 玩法保留）
  ├── 关卡选择                ← v0.2 已有，未来扩展
  │     └── 一·荒山古道
  └── 设置
```

### 3.2 局内循环（与 v0.2 一致，仅角色层不同）

```
选择角色 → 进入劫境
   ↓
开局只有该角色的【初始技能】（不同角色不同）
   ↓
击杀敌人 → 修为 → 悟道选择
   ↓
解锁该角色的【辅助武器】（2~3 件）
   ↓
强化武器 / 提升属性 / 触发【角色专属机制】
   ↓
5 分钟后 Boss（v0.2 荒年兽）
   ↓
击败 → 封印完成
```

### 3.3 与 v0.2 系统的兼容矩阵

| v0.2 系统 | v0.3 改动 |
|---|---|
| StageDirector | 不动 |
| 敌人 / 精英 / Boss | 不动 |
| 镇妖碑 | 不动 |
| weapon_base.gd | 不动（孙悟空武器继承相同基类） |
| 升级池 | **改动**：按当前角色过滤可见技能 |
| HUD | **改动**：新增「角色专属能量」UI 元素 |
| Main 场景 | **改动**：玩家节点根据所选角色加载不同武器组 |

## 4. 玩法机制扩展

### 4.1 角色专属能量条（新机制）

每个角色有一条独立的资源条（HUD 右上角），充能方式和效果各不相同：

| 角色 | 能量名 | 充能方式 | 满后效果 |
|---|---|---|---|
| 修行者（v0.2） | 无 | — | — |
| **孙悟空（v0.3）** | **灵气** | 击杀敌人 +1 | 自动触发七十二变（详见 §5.3） |
| 哪吒 | 三昧真火 | 受伤回火 | 下次攻击范围+50%、伤害+30% |
| 杨戬 | 天眼槽 | 持续战斗 +2/s，击杀加成 | 下次攻击重创/秒杀 |
| 女娲 | 造化（五色轮） | 每 4 秒自动切换元素 | 元素改变技能附加效果 |
| 盘古 | 开天力 | 时间 + 行为 | 攻击伤害倍率 1.0~2.5x |

**v0.3 实施：仅孙悟空的「灵气」需要落地。**

### 4.2 升级池过滤（新机制）

`_get_upgrade_options()` 需要按当前角色过滤：

```text
升级池 = 全局通用项 + 当前角色专属项
全局通用项：气血上限、移速、拾取半径、修为获取、伤害减免（属于「修行」类）
当前角色专属项：
  - 修行者：追魂符 / 飞剑 / 雷电符咒 / 八卦阵 / 爆裂符 / 山河印
  - 孙悟空：金箍棒 / 金箍棒变长 / 毫毛分身
```

未持有该技能时，对应的"强化"选项不应出现在升级池。

### 4.3 五行相克（设计预留，v0.3 不实现）

| 元素 | 克 | 怕 |
|---|---|---|
| 金 | 木 | 火 |
| 木 | 土 | 金 |
| 水 | 火 | 土 |
| 火 | 金 | 水 |
| 土 | 水 | 木 |

未来部分敌人/Boss/技能将标记元素属性。克制时伤害 +30%，被克时 -20%。**v0.3 暂不实现，仅在角色与技能 metadata 中预留 `element` 字段。**

## 5. v0.3 主角：孙悟空 · 齐天大圣

### 5.1 神话来源

《西游记》（公共领域，吴承恩，明代）。关键元素：金箍棒（如意金箍棒）、七十二变、毫毛分身、火眼金睛。

### 5.2 游戏内身份

**「弼马温」** —— 自嘲式称号，符合 v0.2 暗黑志怪感。

**定位**：混战之王，越乱越强。最强 AOE 选手，不擅长单体高血量。

### 5.3 视觉方向（原创表达）

- 黑红剪影 + 头戴金色单线圆环（不画毛发、面部）
- 金箍棒剪影显示为简化棍棒（避免雕花细节）
- 七十二变形态：**青烟 + 小猴/鸟/鱼等小型剪影**（皆为色块剪影，不画细节）
- 战斗时脚下浮现淡红云纹（区别于哪吒的青莲、女娲的五色环）

### 5.4 基础属性

| 属性 | 值 | 备注（与 v0.2 修行者对比） |
|---|---|---|
| 气血上限 | 100 | 与修行者相同 |
| 移速 | 230 | +15%（修行者 200） |
| 拾取半径 | 60 | +20%（修行者 50） |
| 伤害减免 | 0% | 无 |

### 5.5 专属能量：灵气

| 字段 | 值 |
|---|---|
| 最大值 | 30 |
| 充能方式 | 击杀普通敌人 +1，精英 +5，Boss 不触发 |
| 触发方式 | 满 30 自动触发「七十二变」（玩家无需操作） |
| 效果 | 3 秒内：伤害 +50%、移速 +30%、敌人无法选定为攻击目标（无敌） |
| 视觉表现 | 玩家剪影变成小猴剪影 + 青烟环绕 |
| 触发后 | 灵气清零 |

**HUD 显示**：右上角圆形进度环，满 30/30 时金色高亮 + 微弱脉冲特效。

### 5.7 设计意图说明

- **如意金箍棒** vs v0.2 的「八卦阵」：相似的近身旋转，但金箍棒**范围更小（90 vs 150）、DPS 更高、强迫贴脸**。玩法节奏完全不同。
- **金箍棒·变长** vs v0.2 的「飞剑」：都是穿透方向技，但金箍棒是**屏幕级 + 击退**，且只朝玩家朝向（飞剑朝最近敌人）。强调玩家对走位方向的控制。
- **毫毛分身** vs v0.2 的「山河印」：都是高冷却 AOE，但毫毛是**分散自爆 + 主动出击**，山河印是**单点砸落**。两者风格区别明显。
- **七十二变** 的"3 秒无敌"机制是孙悟空的标志性容错：让玩家在混战中通过击杀获得喘息，符合"越乱越强"定位。

### 5.8 数值平衡基线

参考 v0.2 修行者已有数值：

| 角色 | 5 分钟单局期望 DPS | 备注 |
|---|---|---|
| v0.2 修行者（满构筑） | ~600 DPS | 基准 |
| v0.3 孙悟空（满构筑） | ~700 DPS | 略高（因移速高、混战收益强） |

七十二变触发期间瞬时 DPS 可达 1050（700 × 1.5），但靠击杀积累灵气，整体均摊与修行者持平。

## 6. 附录 A：未来角色预案（v0.4+）

以下为完整设计稿，**v0.3 不实施**。每个角色保留详尽设计是为了：
1. 给「角色基类」预留足够多的接口需求
2. 让 v0.3 实施时不会做出限制 v0.4 扩展的早期决策

### 6.1 哪吒 · 莲花化身（v0.4 计划）

**定位**：多武器立体覆盖（同时有近战 / 投射 / 控场）

**视觉**：暗红剪影 + 青莲底光 + 朱砂火纹

**专属能量**：三昧真火（受伤回火，火满后下次攻击范围 +50%、伤害 +30%）

**武器组合**：
- 火尖枪（初始）：方向投射 + 灼烧地面（damage 18 / cd 1.2s / pierce 2）
- 混天绫（解锁）：范围束缚 + 减速 + 持续伤害（damage_tick 4 / duration 3s）
- 乾坤圈（解锁）：自动锁定 + 回旋两段（damage 28 / cd 3s）

**强化锁机制**：三件武器全部解锁后，悟道池出现「**三才合击**」进化项。

### 6.2 杨戬 · 二郎真君（v0.4 计划）

**定位**：单体爆发 + 召唤（精英/Boss 杀手）

**视觉**：银白剪影 + 第三眼位置一道金色直线 + 哮天犬黑色幼狼剪影

**专属能量**：天眼槽（持续战斗 + 击杀充能，满后下一击重创/秒杀）

**武器组合**：
- 三尖两刃刀（初始）：近战三段斩（damage 15×3 / cd 2s）
- 哮天犬（解锁）：召唤宠物自主追击（damage 12 / interval 1.5s）
- 天眼真火（解锁）：全屏锁定最低血敌人（damage 80 / cd 8s）

### 6.3 女娲 · 创世大母（v0.5 计划）

**定位**：元素循环 + 自疗 + 阵地战

**视觉**：五色光环剪影 + 飘带 + 身后破碎五色石

**专属能量**：造化（五色轮，每 4 秒自动切换金/木/水/火/土）

**武器组合**：
- 补天石（初始）：天降单点 + 元素特效（damage 30 / cd 1.5s）
- 五色丝（解锁）：脚下持续区域伤害（damage_tick 5 / 无 cd）
- 造人术（解锁）：召唤短期分身（damage 15 / lifetime 10s / cd 15s）

### 6.4 盘古 · 开天大神（终极解锁）

**定位**：蓄力爆发 · 反高频（颠覆游戏节奏）

**视觉**：巨大灰黑剪影（模型大 30%）+ 混沌团 + 屏幕级开天斧剪影

**基础属性**：气血 200（极高）、移速 140（极慢）、体型 1.3x

**专属能量**：开天力（时间累积，伤害倍率 1.0~2.5x，攻击消耗开天力）

**武器组合**：
- 开天斧（初始）：超大十字斩（damage 60×倍率 / cd 6s）
- 阴阳二气（解锁）：双追踪光球 + 合击额外伤害（damage 25×2 / cd 4s）
- 开辟（解锁，终极大招）：全屏清场（damage 300 / cost 100 开天力）

## 7. 实施路径建议

### 7.1 v0.3 推荐开发顺序

1. **角色基类（`character_base.gd`）**：定义共享接口（属性、专属能量、初始武器列表、升级池过滤）
2. **角色选择 UI**：主菜单新增按钮，进入角色选择子界面（v0.3 简单 List 即可）
3. **修行者重构**：把 v0.2 已有的玩家脚本/技能重新归类到 `character/cultivator.gd`，作为 character_base 的子类。**行为不变**，只是代码组织调整。
4. **孙悟空角色**：实现 `character/sun_wukong.gd` + 灵气 + 七十二变
5. **孙悟空武器**：金箍棒、金箍棒变长、毫毛分身
6. **升级池过滤**：在 `_get_upgrade_options()` 加角色过滤逻辑
7. **HUD 改造**：新增「角色专属能量」UI 元素
8. **默认角色切换**：游戏启动默认选孙悟空
9. **v0.3 QA**：手测两个角色完整 5 分钟单局

### 7.2 技术架构提示

```text
scripts/
  character/
    character_base.gd          ← 新基类
    cultivator.gd              ← 修行者（v0.2 重构后归位）
    sun_wukong.gd              ← 孙悟空
    # nezha.gd / yangjian.gd / nvwa.gd / pangu.gd  ← v0.4+
  weapon/
    cultivator/                ← v0.2 已有，仅迁移目录
      talisman_weapon.gd
      flying_sword_weapon.gd
      thunder_law_weapon.gd
      bagua_array_weapon.gd
      explosive_talisman_weapon.gd
      mountain_seal_weapon.gd
    sun_wukong/                ← v0.3 新增
      jingu_bang_weapon.gd
      jingu_bang_extend_weapon.gd
      hair_clone_weapon.gd
```

注：移动 v0.2 武器文件**会改动场景引用**（.tscn 中的 script_path），需要 reviewer 严格审查无引用断裂。

### 7.3 用户体验细节

- 角色选择 UI 应显示每个角色的：**专属能量名称、流派定位一句话、初始技能名**
- 进入游戏后 HUD 左下角显示**当前角色名 + 等级（v0.3 等级固定为 1）**
- 七十二变触发瞬间应有**屏幕轻微震动 + 玩家剪影变形动效**，玩家必须感受到这是大事件

### 8.2 开放问题（需用户决策）

## 9. 验收标准（v0.3 主线）

v0.3 完成时应满足：

1. 主菜单可选择「孙悟空」或「修行者」开始游戏
2. 选择孙悟空进入游戏，HUD 显示「灵气」能量条

7. 两个角色都能正常完成 5 分钟单局（生存到 Boss 出现并击败荒年兽）
8. 控制台无红色脚本错误，无场景引用断裂
