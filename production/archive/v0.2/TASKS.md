# MythSurvivor v0.2 开发任务清单

本文档根据 [core_gameplay_v_02.md](core_gameplay_v_02.md) 拆解 v0.2 开发任务。

v0.2 的目标是完成第一关“荒山古道”的 5 分钟闯关闭环：

```text
进入关卡
-> 妖潮刷新
-> 击杀敌人掉落修为
-> 吸收修为并升级悟道
-> 解锁/强化技能
-> 镇妖碑风险收益目标
-> 5 分钟后 BOSS 出现
-> 击败 BOSS 后通关
```

## 开发规则

- 每个功能使用独立分支。
- 写代码任务默认走 `pm_planner -> code_explorer -> feature_worker -> reviewer -> qa_tester`。
- 不在一个任务中同时实现多个大功能。
- 不修改无关系统。
- `main` 保持稳定。
- 提交前确认 `git status` 和修改范围。
- 当前网络不可用时，只做本地提交，等待网络恢复后再 push。

## 阶段 2：关卡计时与闯关框架

- [x] 新增关卡计时系统。
  - 分支建议：`codex/stage-timer`
  - 内容：5 分钟关卡计时、阶段事件触发、HUD 显示“历劫时间”。

## 阶段 4：技能扩展

- [x] 新增八卦阵技能。
  - 分支建议：`codex/skill-bagua-array`
  - 内容：玩家周围旋转法阵，对近身敌人持续造成伤害。

  - 参数：`damage`、`cooldown`、`speed`、`lifetime`、`explosion_radius`、`explosion_damage`。
  - 强化项：爆炸范围、爆炸伤害、溅射次数。
  - 验收：命中后爆炸伤害范围内敌人，不破坏追魂符/符箓弹系统。

- [x] 预留或新增山河印初版。
  - 分支建议：`codex/skill-mountain-seal`

  - 建议：v0.2 时间紧时只做低成本初版或资源/升级池预留。
  - 验收：高冷却、高范围、高收益，不影响普通技能节奏。

## 推荐开发顺序

1. 技能解锁与升级池整合。
2. 关卡计时系统。
3. 5 分钟 BOSS 触发框架。
4. 镇妖碑基础机制。
5. 八卦阵技能。
6. 爆裂符技能。
7. 敌人参数配置和 2-3 种新敌人。
8. 精英怪框架和山魈精英。
9. 荒年兽 BOSS 初版。
10. UI 术语包装。
11. 数值调优。
12. v0.2 QA。
13. v0.2 发布。

## 可并行任务

- 文档整理、QA 清单、UI 文案可以并行。
- 八卦阵和爆裂符可以并行，但必须避免同时修改同一段升级池逻辑。
- 纸人妖、狐妖、石傀可以在敌人参数配置完成后并行。
- 荒年兽不同技能可以在 BOSS 基础框架完成后并行。

## 不建议并行任务

- 关卡计时与 BOSS 触发框架不建议拆开独立推进。
- 镇妖碑奖励和风险事件不应早于镇妖碑基础机制。
- 数值平衡不应早于技能、敌人和 BOSS 初版。
- 发布任务必须在 QA 通过后进行。
