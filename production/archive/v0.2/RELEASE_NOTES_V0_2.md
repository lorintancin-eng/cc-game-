# MythSurvivor v0.2 发布说明草案

状态：发布准备文档草案，尚未执行最终发布。

## 版本目标

v0.2 目标是完成“荒山古道”5 分钟单局闭环：开局战斗、妖潮推进、修为拾取、悟道升级、镇妖碑风险收益目标、5 分钟 BOSS、击败 BOSS 后通关。

## 功能范围

- 关卡计时与阶段事件：历劫时间 HUD、4:30 BOSS 预警、5:00 BOSS 触发。
- 技能与升级池扩展：飞剑、雷电符咒、八卦阵、爆裂符、山河印，以及对应解锁/强化项。
- 敌人扩展：纸人妖、狐妖、石傀、鬼火、精英框架、精英词缀、山魈精英。
- 镇妖碑机制：单局目标生成、范围封印进度、完成奖励、封印期间风险事件。
- BOSS 荒年兽：基础追击、冲撞、范围爆裂、召唤、低血暴怒、死亡通关触发。
- UI 与术语包装：气血、修为、境界、悟道、镇妖数、历劫时间、道消身陨、再入劫境、封印完成。
- 数值与节奏：5 分钟妖潮节奏、XP/升级节奏、主要技能数值调整。
